Ограниченный сертификат минцифры

Личный root CA + name-constrained proxy корня «Russian Trusted Root CA». Доверие минцифре только для доменов из вашего списка. Всё генерируется локально в браузере — ключи никуда не отправляются. project.md

По одному в строке; поддомены включаются автоматически (gosuslugi.ru покрывает и www.gosuslugi.ru). Комментарии после # игнорируются.
По умолчанию сертификаты выпускаются бессрочными (до 9999-12-31).
Файл root.pem из прошлой генерации (приватный ключ + сертификат). Если не указан — будет создан новый root. Если NC вашего root не покрывает новый список доменов — сертификат root будет перевыпущен на том же ключе.

Результат

Сохраните root.pem! Файл содержит приватный ключ вашего CA. Потеряете — новая генерация потребует новый root и переустановку сертификатов на всех устройствах. Храните файл в безопасном месте; при необходимости защитите паролем (age / 7z / зашифрованный архив).

Проверки

Установка (после скачивания файлов)

Скачайте файлы и выполните команды. Замените пути на свои.

Linux (openssl / ca-certificates) 
sudo cp root.crt /usr/local/share/ca-certificates/restricted-ru-root.crt
sudo cp proxy.crt /usr/local/share/ca-certificates/restricted-ru-proxy.crt
sudo update-ca-certificates

Firefox использует собственное хранилище: настройте корпоративную политику policies.json с "certificates": {"Install": ["/path/root.crt", "/path/proxy.crt"]} или импортируйте через certutil -d db:.

Windows (cmd от администратора) 
certutil -addstore -f Root root.crt
certutil -addstore -f CA proxy.crt
macOS 
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain root.crt
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain proxy.crt
Удаление

Linux: удалите /usr/local/share/ca-certificates/restricted-ru-*.crt и запустите sudo update-ca-certificates --fresh. Windows: certutil -delstore Root "restricted-russian-ca Personal Root" и удалите proxy из промежуточного хранилища. macOS: sudo security delete-certificate -c "restricted-russian-ca".

Как это работает

Оригинальный рут минцифры не устанавливается. Вместо него ставятся: ваш личный root и proxy-сертификат, в котором скопированы имя и публичный ключ рута минцифры, но подписан он вашим root и содержит критическое расширение nameConstraints: доверие только DNS-именам из вашего списка, IP-сертификаты исключены. Сайты вне списка будут отклоняться с ошибкой сертификата — это ожидаемое поведение.
